# BMW Sales Data Analysis (In Progress)

This project focuses on exploratory data analysis (EDA) of BMW vehicle sales data (2010–2024) across global regions.

⚠️ Status: Currently in the data analysis phase. Modeling stage is planned.

---

## 📊 Dataset
- Source: Kaggle
- Size: 50,000 rows × 11 columns
- Includes features such as model, year, engine size, mileage, transmission type, fuel type, price, sales volume, and region.

---

## 🔎 Completed Phase: Exploratory Data Analysis

- Performed structured exploratory data analysis (EDA)
- Analyzed distributions of numerical variables
- Investigated relationships between price, mileage, engine size, and sales volume
- Applied categorical encoding techniques
- Conducted correlation analysis
- Prepared a cleaned dataset ready for modeling

---

## 🚀 Upcoming Phases

- Feature engineering and feature selection
- Model selection and training
- Model evaluation using regression metrics (MAE, RMSE, R²)
- Performance comparison and optimization
- Final analytical report and insights

---

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

---

## 🎯 Project Objective
To analyze BMW sales patterns and build a predictive framework for understanding key factors influencing sales performance.
